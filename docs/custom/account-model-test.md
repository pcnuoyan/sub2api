# 账号模型测试（自有扩展）

本模块基于 `custom` 分支开发，管理员入口为 `/admin/account-model-test`。菜单、路由和依赖注入是与上游的公共接入点；任务、结果表和页面组件独立维护。原账号测试弹窗和原定时连接检测沿用原流程。

## 使用

选择同一个模型、题目与思考强度，在账号卡片上手动发起测试。`6a` 是固定候选别名，是否能调用取决于账号的模型映射和上游支持。模型也可以手动输入。显式思考强度不受当前协议支持时会报错，不会静默改成另一个强度。

预设包含糖果计算题和“鹈鹕骑自行车”SVG 动画题。修改题面后按自定义题保存。糖果题只检查请求成功和非空回答，答案仍需人工判断；动画题还检查完整 SVG 与绘图元素，不能据此判断画面质量或语义正确。

页面读取已有账号元数据、用量及倍率快照，不因打开页面自动调用模型或刷新上游额度。缺失用量显示 `—`，已知零用量显示 `0%`。测试会消耗真实账号额度，并与业务请求共用上游配额。

## 执行与保存

- 服务端独立运行任务，切页或刷新不会取消；全局最多并发 5 个任务，同一账号禁止同时重复测试。
- 单任务限时 20 分钟（包含排队），可手动取消。重启后的未完成任务记为中断，不自动重试。
- 成功必须有明确的完成终态且回答非空；失败或取消保留可取得的部分回答。超长回答按服务端限制截断并标记失败。
- PostgreSQL 按管理员隔离，每账号保留请求时间最新的一条，每管理员最多 500 条。较晚完成的旧请求不能覆盖新请求。
- 清空操作取消该管理员现有任务并保存清空水位；清空前的结果不能通过后台完成或 JSON 导入重新出现。
- 入库失败时，服务端仅暂存有界的近期结果。页面会标注未保存，可及时导出；进程退出后不能保证恢复这些内存结果。
- 导出 JSON 绑定管理员 ID。本模块支持自身版本化格式；其他二开版的未知浏览器键名和数据结构需要额外转换，不能保证自动迁移。

动画预览使用不授予脚本和同源能力的 iframe，清理后的 HTML/SVG 受到禁止外部资源的 CSP 限制。原始回答只以转义文本展示，可查看源码。依赖 JavaScript 或外部资源的动画不会运行。

## 接口

接口均由现有管理员鉴权保护，身份来自服务端认证上下文。普通用户与受限管理密钥不能访问。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET / POST | `/api/v1/admin/account-model-test-jobs` | 查询 / 创建任务 |
| DELETE | `/api/v1/admin/account-model-test-jobs/:id` | 取消本管理员任务 |
| GET / POST / DELETE | `/api/v1/admin/account-model-test-results` | 查询 / 导入 / 清空结果 |

## 维护边界

迁移文件为 `900001_custom_account_model_tests.sql`，只新增本模块三张表。迁移执行器按完整文件名记录 checksum；此自有编号不占用上游正常递增编号，后续也不要修改已应用迁移。

执行器通过 PostgreSQL 会话锁限制单个实例运行。同一数据库的第二个应用实例不能接管在线执行器；失去锁会停止接受新任务并取消本实例任务。这不是跨实例任务调度系统。

本次首期实现管理员手动测试。附件中的每日定时鹈鹕测试及外部 `/keydosage` 匿名展示不属于首期交付：不创建定时请求，也不公开管理员结果。后续定时功能应默认关闭，并单独接入外部用量页项目。

## 本地验证

常规验证使用模拟上游和测试仓储，不需要真实账号密钥。实际 PostgreSQL 用例使用独立构建标签，并只接受回环地址；创建随机临时 schema，结束后删除该 schema：

```powershell
$env:ACCOUNT_MODEL_TEST_DATABASE_URL = 'postgres://testuser@127.0.0.1:55439/sub2api_model_test?sslmode=disable'
go test -tags modeltestdb ./internal/repository -run '^TestAccountModelTestPostgres$' -count=1
```

以上命令在 `backend` 目录执行，连接地址需替换为自己的本地测试数据库。该用例验证迁移重复执行、管理员隔离、新旧结果排序、并发清空、500 条上限、重启恢复和实例锁；不执行上游模型请求。
